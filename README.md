# Ginger-Downloader

Ginger-Downloader is a small tui application that helps you download packages from [GingerRush](https://gingerrush.com). It will scan your local database and try downloading the packages that presents on the server while not on your disk.

> [!warning]
> This application is still far from solid, use it at your own risk

## How to use

Arrow key or hjkl to move the cursor. Press enter key for selection.
